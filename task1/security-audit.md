# Аудит мер безопасности (as-is)

## Политики и управление доступом

| Область | Состояние   | Проблемы                                     |
| ------- | ----------- | -------------------------------------------- |
| AD      | есть        | нет принципа минимально необходимого доступа |
| RBAC    | отсутствует | сотрудники видят чужие данные                |
| MFA     | отсутствует | риск компрометации учёток                    |
| Логи    | отсутствуют | невозможно расследовать инцидент             |

## Хранение данных

* Медкарты → не шифруются
* Финансовые Excel → не шифруются
* Данные пациентов → доступ сотрудникам без ограничений
* Нет политики хранения / уничтожения данных

## Сети

* Windows Server на объекте — single point of failure
* Нет DMZ
* ККМ подключены по TCP без полноценного шифрования
* Нет сетевой сегментации (врач ↔ касса ↔ склад в одной сети)

## Соответствие ФЗ-152

Нарушения:

* Нет СОУТ
* Нет модели угроз (ГУ ИБ ФСТЭК)
* Нет журнала доступа
* Нет политики удаления персональных данных
* Нет шифрования уровня КС2/КС3
