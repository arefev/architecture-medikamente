# Список проблемных зон

1. Все данные пациентов хранятся в Excel, JPG, PDF на общем сетевом диске.
2. У сотрудников нет ролевого разграничения доступа (RBAC/ABAC).
3. Нет шифрования данных ни в покое, ни в передаче.
4. Нет аудита действий пользователей.
5. Нет выявления аномалий (UEBA).
6. Нет Data Lineage — невозможно понять, кто и куда пересылал данные.
7. 1С работает в файловом режиме → можно подменить файл.
8. Нет централизованного управления конфиденциальными данными.
9. Нет политики retention — данные хранятся вечно.
10. Дублирование данных нарушает Data Minimization.
11. Нет защиты медкарт как особо чувствительных данных по закону.
12. Мобильного приложения пока нет → сценарии будущей безопасности не подготовлены.
13. Нет защиты API (которых пока нет, но будут) — нет API Gateway, audit logging, rate limiting.
