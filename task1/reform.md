# Улучшения

## Список данных и способы защиты

| Категория               | Степень чувствительности | Метод защиты                      |
| ----------------------- | ------------------------ | --------------------------------- |
| ФИО                     | PII                      | псевдонимизация, шифрование       |
| Паспортные данные       | критичные                | шифрование (AES-256), минимизация |
| Адрес                   | PII                      | маскирование                      |
| Телефон / email         | PII                      | токенизация                       |
| Диагнозы                | особо чувствительные     | сегментация, шифрование + ABAC    |
| Результаты анализов     | особо чувствительные     | тегирование + доступ по ролям     |
| Медицинские изображения | особо чувствительные     | хранение в закрытом сегменте      |
| Платёжные данные        | финансовые               | шифрование, журналирование        |
| Логи операций           | не ПДн, но важны         | неизменяемое хранилище            |

## Механизм тегирования данных

**Теги:**

* `pii.basic` — базовые ПДн
* `pii.sensitive` — паспорт, контакты
* `health.basic` — визиты, рецепты
* `health.critical` — диагнозы, анализы
* `finance` — оплата
* `internal-only` — служебная информация
* `restricted` — доступ только врачам
* `external.safe` — можно отдавать партнёрам

**Тегирование используется для:**

* автоматической проверки релизов
* фильтрации полей в API Gateway
* динамического ABAC

## Меры, инструменты и способы защиты

### Приложение: инструменты

* Keycloak / OpenID Connect → IAM
* Vault → управление ключами
* API Gateway (Kong / Tyk / Apigee / Yandex API-Gateway)
* Сегментация сетей → VLAN
* SIEM → Graylog / ELK / Positive IB
* DLP (опционально)
* Object Storage (S3-совместимый)
* Postgres с TDE или Always Encrypted
* ClickHouse для аналитики
